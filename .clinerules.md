# Environment
- Работаю на Windows, терминал PowerShell (НЕ bash/zsh/cmd)
- Все команды в терминале давай СТРОГО в PowerShell-синтаксисе
- НЕ используй Linux-команды: find, head, tail, grep, ls -la, cat, rm, mv
- НЕ используй cmd.exe синтаксис: dir /s /b, 2>nul, findstr
- PowerShell-эквиваленты:
  - вместо ls -la → Get-ChildItem или dir
  - вместо find → Get-ChildItem -Recurse -Include
  - вместо grep → Select-String
  - вместо rm → Remove-Item
  - вместо cat → Get-Content
  - вместо head -50 → Select-Object -First 50

# Task discipline
- НИКОГДА не переходи от Plan-режима к Act-режиму без явного 
  разрешения пользователя, даже если план выглядит полностью готовым
- Если задача состоит из нескольких пунктов — жди ОТДЕЛЬНОГО 
  подтверждения на КАЖДЫЙ пункт перед тем, как переходить к следующему
- Если пользователь написал "не вноси изменений сразу" или похожую 
  инструкцию — это правило действует ДО КОНЦА задачи, а не только 
  для первого шага
- Не расширяй объём задачи самостоятельно — исправляй только то, 
  что явно перечислено в промпте, даже если видишь другие проблемы 
  в коде (можешь упомянуть их отдельно, но не исправлять без разрешения)
- После каждого изменения файла — кратко объясни, что именно изменено, 
  и жди подтверждения перед следующим шагом
