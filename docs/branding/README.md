# Branding i Wytyczne Wizualne (Branding Guidelines)

## Kolory Marki

- **Główny kolor marki (Brand Green):** `#23870b`
- Kolor ten powinien być używany do głównych akcentów, przycisków akcji (CTA) i kluczowych wyróżnień na stronie.

## Mapowanie Kolorów Systemów

Aby zachować spójność wizualną w interaktywnych wizualizacjach (np. sekcja Hero, schematy budynku), dla poszczególnych systemów inżynieryjnych obowiązują następujące kolory:

- **HVAC:** `#3B82F6` (niebieski)
- **SAP/fire (Systemy Przeciwpożarowe):** `#EF4444` (czerwony)
- **KD (Kontrola Dostępu):** `#22C55E` (jasny zielony)
- **CCTV (Monitoring wizyjny):** `#8B5CF6` (fioletowy)
- **BAS (Automatyka Budynkowa):** `#F97316` (pomarańczowy)
- **BMS (Zarządzanie Budynkiem):** `#23870B` (firmowy zielony)

## Język Treści

- Cała treść widoczna dla odwiedzającego stronę musi być **w pełni w języku polskim**.
- Zapewnia to profesjonalny odbiór na docelowym rynku lokalnym.

## Motyw (Theme)

- Aplikacja posiada zintegrowany **przełącznik trybu jasnego i ciemnego (light/dark theme)**.
- Projektując i modyfikując komponenty, należy zawsze upewnić się, że wspierają one i poprawnie wyświetlają się w obu motywach (używając klas Tailwind takich jak `dark:bg-gray-900` itp.).
